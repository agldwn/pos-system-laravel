# Laravel POS Foundation Application

This project is a basic Point-of-Sale application created using Laravel 12 and PHP 8.2.

## Features

- Landing page
- About page
- Customer Accounts page
- User Accounts page
- Navigation links between all pages
- Static PHP arrays for customer and user records
- Blade `@foreach` loops for displaying records

## Routes

- `/` - Landing page
- `/about` - About page
- `/customers` - Customer Accounts
- `/users` - User Accounts

## Requirements

- PHP 8.2 or newer
- Composer
- Laravel
- Node.js and NPM
- Git
